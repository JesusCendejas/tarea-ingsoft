****CU-11 · Consultar escenas****

| Campo                  | Contenido |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Actor principal        | Usuario |
| Objetivo               | Ver las escenas guardadas en su cuenta y activar una en un toque. |
| Precondición           | El usuario tiene sesión iniciada. |
| Escenario principal    | 1. El usuario abre la sección de escenas.2. El sistema muestra las escenas guardadas en su cuenta, cada una con los dispositivos que incluye y una vista previa.3. El usuario toca una escena.4. El sistema aplica a cada dispositivo su configuración guardada (efecto, animación, color, brillo). |
| Flujos alternos        | 4a. Un dispositivo de la escena está desconectado: el sistema aplica la escena en los dispositivos disponibles y avisa cuáles se omitieron.4b. El usuario no tiene escenas: el sistema muestra una guía para crear la primera. |
| Postcondición          | Los dispositivos disponibles de la escena reproducen su configuración guardada. |
| Requisitos que realiza | RF-19, RF-21, RF-12 |
