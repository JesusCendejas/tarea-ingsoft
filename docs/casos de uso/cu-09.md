****CU-09 · Actualizar el firmware de un dispositivo (OTA)****

| Campo                  | Contenido                                                                                                                                                                                                                                                                                           |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Actor principal        | Usuario                                                                                                                                                                                                                                                                                             |
| Objetivo               | Instalar la versión más reciente del firmware en un dispositivo propietario.                                                                                                                                                                                                                        |
| Precondición           | El dispositivo es propietario, está vinculado y conectado. Hay una versión nueva disponible.                                                                                                                                                                                                        |
| Escenario principal    | 1. El usuario abre el estado del dispositivo.2. El sistema indica que hay una actualización disponible.3. El usuario confirma la actualización.4. El sistema envía el nuevo firmware al dispositivo.5. El dispositivo se reinicia con la versión nueva y el sistema muestra la versión actualizada. |
| Flujos alternos        | 4a. La actualización falla: el dispositivo vuelve a su versión anterior y el sistema lo reporta.1a. El dispositivo no es propietario: el sistema no ofrece la opción de actualización.                                                                                                              |
| Postcondición          | El dispositivo corre la versión nueva del firmware, o la anterior si falló.                                                                                                                                                                                                                         |
| Requisitos que realiza | RF-16                                                                                                                                                                                                                                                                                               |
