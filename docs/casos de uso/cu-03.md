****CU-03 · Consultar el estado de un dispositivo****

| Campo                  | Contenido                                                                                                                                                                                                                                           |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Actor principal        | Usuario                                                                                                                                                                                                                                             |
| Objetivo               | Saber si un dispositivo está conectado y ver sus datos técnicos.                                                                                                                                                                                    |
| Precondición           | El usuario tiene sesión iniciada y al menos un dispositivo vinculado.                                                                                                                                                                               |
| Escenario principal    | 1. El usuario abre su lista de dispositivos.2. El sistema muestra cada dispositivo con su estado (conectado / desconectado).3. El usuario selecciona un dispositivo.4. El sistema muestra IP, MAC, señal WiFi, memoria libre y versión de firmware. |
| Flujos alternos        | 2a. El dispositivo se desconecta mientras el usuario lo mira: el sistema actualiza su estado a desconectado en menos de 30 segundos.                                                                                                                |
| Postcondición          | El usuario conoce el estado actual del dispositivo.                                                                                                                                                                                                 |
| Requisitos que realiza | RF-04, RF-05, RF-06, RNF-03                                                                                                                                                                                                                         |
