****CU-06 · Transmitir una animación en vivo (streaming)****

| Campo                  | Contenido                                                                                                                                                                                                                                                                                                                                        |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Actor principal        | Usuario                                                                                                                                                                                                                                                                                                                                          |
| Objetivo               | Enviar frames de color en tiempo real al dispositivo.                                                                                                                                                                                                                                                                                            |
| Precondición           | El dispositivo está vinculado y conectado.                                                                                                                                                                                                                                                                                                       |
| Escenario principal    | 1. El usuario selecciona el dispositivo y entra al modo streaming.2. El sistema abre el canal de envío de frames.3. El usuario genera los frames (desde el editor en vivo o una fuente externa).4. El sistema transmite los frames al dispositivo, que los reproduce a 30 fps.5. El usuario sale del modo streaming; el sistema cierra el canal. |
| Flujos alternos        | 4a. Había un efecto corriendo: el streaming lo reemplaza; el último comando siempre gana.4b. La conexión se satura: el sistema mantiene la animación fluida descartando frames atrasados.                                                                                                                                                        |
| Postcondición          | El dispositivo mostró la animación transmitida y queda listo para el siguiente comando.                                                                                                                                                                                                                                                          |
| Requisitos que realiza | RF-10, RF-11, RNF-01                                                                                                                                                                                                                                                                                                                             |
