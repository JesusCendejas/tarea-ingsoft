****CU-02 · Iniciar sesión****

| Campo                  | Contenido |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Actor principal        | Usuario |
| Objetivo               | Entrar a su cuenta de MoonLight para usar sus dispositivos, animaciones y escenas. |
| Precondición           | El usuario ya tiene una cuenta registrada. |
| Escenario principal    | 1. El usuario abre la página y elige "Iniciar sesión".2. El sistema pide correo y contraseña.3. El usuario los ingresa.4. El sistema valida las credenciales.5. El sistema abre la sesión y muestra la lista de dispositivos del usuario. |
| Flujos alternos        | 4a. Correo o contraseña incorrectos: el sistema avisa y permite reintentar.4b. El usuario olvidó su contraseña: el sistema ofrece recuperarla por correo. |
| Postcondición          | El usuario tiene sesión iniciada y acceso a sus dispositivos, animaciones y escenas. |
| Requisitos que realiza | RF-17 |
