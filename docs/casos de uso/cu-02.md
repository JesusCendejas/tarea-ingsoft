****CU-02 · Vincular un dispositivo****

| Campo                  | Contenido                                                                                                                                                                                                                                                                                                                            |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Actor principal        | Usuario                                                                                                                                                                                                                                                                                                                              |
| Objetivo               | Agregar un dispositivo a su cuenta para poder controlarlo.                                                                                                                                                                                                                                                                           |
| Precondición           | El usuario tiene sesión iniciada. El dispositivo está encendido y conectado a internet.                                                                                                                                                                                                                                              |
| Escenario principal    | 1. El usuario elige "Agregar dispositivo" desde su lista.2. El sistema pide el código del dispositivo (la MAC impresa en la etiqueta).3. El usuario lo escribe y confirma.4. El sistema verifica que la MAC no esté vinculada a otra cuenta.5. El sistema vincula el dispositivo y lo muestra en la lista del usuario con su estado. |
| Flujos alternos        | 4a. La MAC ya está vinculada a otra cuenta: el sistema rechaza el registro y avisa al usuario.4b. El dispositivo no responde: el sistema lo agrega pero lo marca como desconectado.                                                                                                                                                  |
| Postcondición          | El dispositivo queda vinculado a la cuenta y aparece en la lista del usuario.                                                                                                                                                                                                                                                        |
| Requisitos que realiza | RF-02, RF-03, RF-05, RNF-07                                                                                                                                                                                                                                                                                                          |
