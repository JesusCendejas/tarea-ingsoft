****CU-13 · Agregar colores favoritos****

| Campo                  | Contenido |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Actor principal        | Usuario |
| Objetivo               | Guardar los colores que más usa para aplicarlos rápido en cualquier dispositivo. |
| Precondición           | El usuario tiene sesión iniciada. |
| Escenario principal    | 1. El usuario abre el selector de color de un dispositivo.2. El usuario elige un color con el selector o pica uno existente de la tira.3. El usuario toca "Agregar a favoritos".4. El sistema guarda el color en la lista de favoritos de la cuenta.5. El color queda disponible en el selector de color de todos sus dispositivos. |
| Flujos alternos        | 3a. El color ya está en favoritos: el sistema avisa y no lo duplica.4a. La lista de favoritos está llena: el sistema avisa y ofrece eliminar alguno. |
| Postcondición          | El color queda guardado en la cuenta y disponible en todos los dispositivos del usuario. |
| Requisitos que realiza | RF-22 |
