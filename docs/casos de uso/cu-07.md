****CU-07 · Crear una animación personalizada****

| Campo                  | Contenido                                                                                                                                                                                                                                                                                                                  |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Actor principal        | Usuario                                                                                                                                                                                                                                                                                                                    |
| Objetivo               | Diseñar una animación propia, frame por frame, y guardarla.                                                                                                                                                                                                                                                                |
| Precondición           | El usuario tiene sesión iniciada y al menos un dispositivo vinculado.                                                                                                                                                                                                                                                      |
| Escenario principal    | 1. El usuario abre el editor de animaciones.2. El sistema muestra la cuadrícula de LEDs del dispositivo y la línea de tiempo de frames.3. El usuario define el color de cada LED por frame y la duración de cada frame.4. El usuario guarda la animación con un nombre.5. El sistema la registra en la cuenta del usuario. |
| Flujos alternos        | 4a. El usuario quiere probarla antes de guardar: el sistema la envía al dispositivo en modo streaming y vuelve al editor.                                                                                                                                                                                                  |
| Postcondición          | La animación queda guardada en la cuenta, disponible para enviarse a cualquier dispositivo vinculado.                                                                                                                                                                                                                      |
| Requisitos que realiza | RF-13, RF-14                                                                                                                                                                                                                                                                                                               |
