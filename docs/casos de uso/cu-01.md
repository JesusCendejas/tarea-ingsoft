****CU-01 · Crear una cuenta****

| Campo                  | Contenido                                                                                                                                                                                                                                            |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Actor principal        | Usuario                                                                                                                                                                                                                                              |
| Objetivo               | Registrarse en MoonLight para poder vincular y controlar sus dispositivos.                                                                                                                                                                           |
| Precondición           | El usuario tiene un correo electrónico válido.                                                                                                                                                                                                       |
| Escenario principal    | 1. El usuario abre la página y elige "Crear cuenta".2. El sistema pide correo y contraseña.3. El usuario los ingresa y confirma.4. El sistema verifica que el correo no esté registrado.5. El sistema crea la cuenta e inicia la sesión del usuario. |
| Flujos alternos        | 4a. El correo ya está registrado: el sistema avisa y ofrece iniciar sesión en su lugar.                                                                                                                                                              |
| Postcondición          | La cuenta existe y el usuario queda con sesión iniciada, sin dispositivos vinculados.                                                                                                                                                                |
| Requisitos que realiza | RF-01                                                                                                                                                                                                                                                |
