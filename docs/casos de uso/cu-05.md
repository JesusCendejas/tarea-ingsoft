****CU-05 · Actualizar información del dispositivo****

| Campo                  | Contenido |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Actor principal        | Usuario |
| Objetivo               | Cambiar el nombre u otros datos visibles de un dispositivo vinculado. |
| Precondición           | El usuario tiene sesión iniciada y el dispositivo está vinculado a su cuenta. |
| Escenario principal    | 1. El usuario selecciona el dispositivo y abre sus detalles.2. El usuario elige "Editar información".3. El sistema muestra los campos editables (nombre del dispositivo, habitación).4. El usuario modifica los campos y confirma.5. El sistema guarda los cambios y los refleja en la lista de dispositivos. |
| Flujos alternos        | 4a. El usuario deja el nombre vacío: el sistema rechaza el cambio y pide un nombre válido.4b. El usuario cancela la edición: el sistema descarta los cambios sin modificar nada. |
| Postcondición          | La información del dispositivo queda actualizada en la cuenta del usuario. |
| Requisitos que realiza | RF-18 |
