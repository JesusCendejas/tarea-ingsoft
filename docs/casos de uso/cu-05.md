****CU-05 · Detener el efecto o animación en curso****

| Campo                  | Contenido                                                                                                                |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Actor principal        | Usuario                                                                                                                  |
| Objetivo               | Apagar la animación que está corriendo en un dispositivo.                                                                |
| Precondición           | El dispositivo está vinculado, conectado y reproduciendo algo.                                                           |
| Escenario principal    | 1. El usuario selecciona el dispositivo.2. El usuario toca "Detener".3. El sistema envía la orden y las luces se apagan. |
| Flujos alternos        | 3a. El dispositivo está desconectado: el sistema impide el envío y avisa.                                                |
| Postcondición          | El dispositivo deja de reproducir efectos y animaciones.                                                                 |
| Requisitos que realiza | RF-09, RF-12                                                                                                             |
