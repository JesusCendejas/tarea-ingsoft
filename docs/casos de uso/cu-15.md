****CU-15 · Agregar una habitación****

| Campo                  | Contenido |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Actor principal        | Usuario |
| Objetivo               | Crear una habitación para organizar sus dispositivos y escenas por lugar de la casa. |
| Precondición           | El usuario tiene sesión iniciada. |
| Escenario principal    | 1. El usuario elige "Agregar habitación".2. El sistema pide un nombre para la habitación.3. El usuario escribe el nombre y confirma.4. El sistema crea la habitación y la muestra en la lista de habitaciones de la cuenta. |
| Flujos alternos        | 3a. El usuario deja el nombre vacío: el sistema rechaza el guardado y pide un nombre válido.3b. Ya existe una habitación con ese nombre: el sistema avisa y no la duplica. |
| Postcondición          | La habitación existe en la cuenta y puede recibir dispositivos y escenas. |
| Requisitos que realiza | RF-23 |
