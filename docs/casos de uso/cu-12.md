****CU-12 · Crear una escena****

| Campo                  | Contenido |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Actor principal        | Usuario |
| Objetivo               | Guardar la configuración actual de varios dispositivos para reactivarla junta después. |
| Precondición           | El usuario tiene sesión iniciada y al menos un dispositivo vinculado. |
| Escenario principal    | 1. El usuario elige "Crear escena".2. El sistema muestra la lista de dispositivos vinculados con su configuración actual (efecto, animación, color, brillo).3. El usuario selecciona qué dispositivos incluye la escena y ajusta su configuración.4. El usuario guarda la escena con un nombre.5. El sistema la registra en la cuenta del usuario. |
| Flujos alternos        | 4a. El usuario no selecciona ningún dispositivo: el sistema rechaza el guardado y pide incluir al menos uno.4b. El usuario quiere probarla antes de guardar: el sistema aplica la configuración de la escena a los dispositivos y vuelve al editor. |
| Postcondición          | La escena queda guardada en la cuenta, disponible para activarse en un toque. |
| Requisitos que realiza | RF-20, RF-21 |
