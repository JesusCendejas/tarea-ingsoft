****CU-04 · Activar un efecto predefinido****

| Campo                  | Contenido                                                                                                                                                                                                                                       |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Actor principal        | Usuario                                                                                                                                                                                                                                         |
| Objetivo               | Poner un efecto de luces en un dispositivo en pocos toques.                                                                                                                                                                                     |
| Precondición           | El dispositivo está vinculado y conectado.                                                                                                                                                                                                      |
| Escenario principal    | 1. El usuario selecciona el dispositivo.2. El sistema muestra los efectos disponibles.3. El usuario elige un efecto y ajusta velocidad, brillo o colores si quiere.4. El sistema envía el efecto al dispositivo, que lo reproduce de inmediato. |
| Flujos alternos        | 4a. El dispositivo está desconectado: el sistema impide el envío y avisa que el dispositivo no está disponible.4b. Había una animación corriendo: el efecto nuevo la reemplaza; el último comando siempre gana.                                 |
| Postcondición          | El dispositivo reproduce el efecto elegido con los parámetros indicados.                                                                                                                                                                        |
| Requisitos que realiza | RF-07, RF-08, RF-11, RF-12, RNF-02, RNF-06                                                                                                                                                                                                      |
