****CU-08 · Enviar una animación guardada a un dispositivo****

| Campo                  | Contenido                                                                                                                                                                                                                                     |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Actor principal        | Usuario                                                                                                                                                                                                                                       |
| Objetivo               | Reusar una animación de su biblioteca en cualquiera de sus dispositivos.                                                                                                                                                                      |
| Precondición           | El usuario tiene al menos una animación guardada y el dispositivo destino está conectado.                                                                                                                                                     |
| Escenario principal    | 1. El usuario abre su biblioteca de animaciones.2. El sistema muestra las animaciones guardadas en su cuenta.3. El usuario elige una animación y el dispositivo destino.4. El sistema la transmite al dispositivo, que la reproduce en bucle. |
| Flujos alternos        | 4a. El dispositivo destino es distinto del que inspiró la animación: el sistema adapta la animación a la cantidad de LEDs del destino.4b. El dispositivo está desconectado: el sistema impide el envío y avisa.                               |
| Postcondición          | El dispositivo destino reproduce la animación y la conserva aunque el usuario cierre la página.                                                                                                                                               |
| Requisitos que realiza | RF-15, RF-12                                                                                                                                                                                                                                  |
