****CU-16 · Seleccionar la ubicación de un dispositivo****

| Campo                  | Contenido |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Actor principal        | Usuario |
| Objetivo               | Asignar un dispositivo a una habitación para verlo agrupado por lugar de la casa. |
| Precondición           | El usuario tiene sesión iniciada, el dispositivo está vinculado y existe al menos una habitación. |
| Escenario principal    | 1. El usuario abre los detalles del dispositivo.2. El usuario elige "Cambiar habitación".3. El sistema muestra las habitaciones de la cuenta.4. El usuario selecciona una habitación.5. El sistema asigna el dispositivo a esa habitación y lo muestra agrupado en la lista de dispositivos. |
| Flujos alternos        | 4a. El usuario no tiene habitaciones: el sistema ofrece crear una en el momento.4b. El usuario cancela la selección: el dispositivo conserva su habitación actual. |
| Postcondición          | El dispositivo queda asignado a la habitación elegida y aparece agrupado por ubicación. |
| Requisitos que realiza | RF-24 |
